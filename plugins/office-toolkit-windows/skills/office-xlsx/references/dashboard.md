# Data dashboards

Use for KPI workbooks, management reports, and dashboards with charts or filters.

1. Keep a tidy source/data sheet separate from a compact summary/dashboard sheet.
2. Define KPI formulas from source ranges, label units and time periods, and make the primary question obvious in the sheet order and layout.
3. Choose charts by message: line for time series, column for category comparison, scatter for correlation, and pie only for a small set of clearly proportional parts. Use explicit categories and non-empty anchors.
4. Add restrained conditional formatting or filters only where they improve a decision. Set the dashboard to landscape and fit one page when short; fit width only for tall source sheets.
5. Inspect the HTML preview for clipped labels, `###`, blank chart regions, and unreadable legends; then validate formulas and structure.
