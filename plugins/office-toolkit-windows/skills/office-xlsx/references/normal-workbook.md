# Normal workbooks

Use for ordinary workbooks, trackers, CSV/TSV imports, formula edits, and workbook review.

1. Open or create the target through the shared wrapper; inspect the outline before writing.
2. Build in small batches: headers, data, formulas, then tables/charts and formatting. Keep formula cells live and guard denominators.
3. Set explicit widths, header styling, freeze panes, filters/data validation where inputs need constraints, and useful formats (`0.0%`, dates, and currency with negatives in parentheses).
4. Save, inspect issues and annotated values, validate, then read the HTML preview. Query each Excel error type and fix any visual defect before delivery.

For a chart, use a two-dimensional source range with category labels or explicit series categories. Recheck that the chart source and displayed labels match the cells.
