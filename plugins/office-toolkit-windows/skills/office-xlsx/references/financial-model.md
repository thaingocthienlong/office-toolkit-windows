# Financial models

Use for budgets, forecasts, valuation, operating plans, and three-statement models.

- Separate assumptions, schedules, statements, and summary outputs; use named ranges when they clarify important assumptions.
- Put assumptions in visible input cells with blue text and a source note. Use black for calculations, green for intra-workbook links, red for external links, and yellow fill only for key assumptions needing review.
- Use one decimal for percentages, `0.0x` for multiples, years as text, and zeros as `-`; include the currency unit in the header.
- Link statements and schedules with formulas. Guard every denominator and spot-check cached values on summary cells after dependent formulas are written.

Require a formula/error/visual QA pass before delivery. If the model is a template, label assumptions and formulas clearly but do not invent source data.
