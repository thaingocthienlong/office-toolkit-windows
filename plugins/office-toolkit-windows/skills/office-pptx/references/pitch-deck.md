# Pitch Deck

Use shared wrapper `../../scripts/invoke-officecli.ps1` for every OfficeCLI action. Follow its help surface for arguments and schemas. Never run a network installer, download a CLI, call `officecli` directly, or use a legacy Python/Node Office runtime.

Treat fundraising decks as an investor narrative, not a feature catalog. Unless the brief says otherwise, use this arc: cover, problem, solution, market, product, model, traction, team, financials, ask. Put one investable proposition on each slide.

Diagnose stage before choosing detail. Keep TAM/SAM/SOM, ARR/revenue, CAC/LTV, runway, projections, traction, team credentials, and use of funds internally consistent. Never invent metrics; mark missing inputs.

Use a bundled style only through [Bundled styles](styles.md). Validate through the wrapper for structure, text, notes, slide order, overflow, clipping, contrast, and visual preview.
